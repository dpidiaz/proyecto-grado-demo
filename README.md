# Clutter DEMO — Proyecto de grado

Copia de demostración preparada desde el commit 799dc3f6c81f8f07af3aa9c4f6022a64f2fb8b37 del proyecto, extraída únicamente desde pwa/. No contiene el historial Git ni los cambios locales del checkout de desarrollo.

## Uso

Sirve esta carpeta como sitio estático HTTPS desde su raíz. No necesita Node.js ni un servidor de sincronización. La sincronización con GitHub está desactivada; las ediciones que se hagan desde el navegador se quedan en ese perfil local y no cambian el repositorio.

## Contenido

La demo conserva la PWA, su bundle académico, registros que utiliza la aplicación y los medios asociados. Se excluyeron los scripts del servidor local, lanzadores para Windows, verificadores portables y documentos de apoyo para IA/desarrollo.

## Revisión antes de publicación pública

Esta carpeta es una candidata local, no una autorización automática para publicar todos sus contenidos. Antes de hacerla pública, revisa los permisos y procedencia de las imágenes y PDF, así como los registros de auditoría y las tablas de encuesta que la fuente describe como transcripciones candidatas no verificadas. Confirma que cada contenido incluido pueda mostrarse abiertamente.
